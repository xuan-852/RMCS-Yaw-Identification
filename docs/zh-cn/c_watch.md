## 1. 目标与总体思路

对步兵 C 云台 yaw 轴建立**二阶动力学模型**，用实车数据完成系统辨识，基于辨识参数改进控制，并通过 A/B 对照实验验证。

```
梳理 yaw 数据流 → 下层解耦（隔离试验环境）→ 设计标准激励协议
→ 两轮实车采集 → 二阶+摩擦模型辨识（输出误差法+交叉验证）
→ 模型前馈控制器 → A/B 对照（两轮共 7 组）→ 平台约束分析
```

**两轮工作的定位**：
- **第一轮（09-26）**：建立方法论——激励协议、辨识、A/B 对照全部跑通，模型前馈显著有效
- **第二轮（09-29）**：工程化与加深——28 工况全流程自动化采集、加入安全保护、扩展覆盖域、补测自然遥控数据，并**暴露出平台的两个硬约束**

## 2. 系统背景：yaw 控制数据流

```
遥控器/自瞄 → 角度误差(yaw_angle_error)
  → 角度 PID (kp=10) → 速度参考
  → 速度 PID (kp=13, ki=0.02)，反馈 = IMU 角速度
  → /gimbal/yaw/control_torque
  → LK 力矩-电流换算 → CAN2 0x142（实际约 500 Hz）→ MG4010Ei10
```

关键事实：
- yaw 速度环**无输出限幅**，指令仅受 CAN 电流 ±2048 物理钳位
- 双速度源一致性：电调速度 vs IMU 陀螺实测 corr **0.993**、斜率 0.987
- 主循环 1 kHz，yaw CAN 命令约 500 Hz

## 3. 试验环境：下层解耦

**问题**：原始配置上电后四臂收到 59° 高位（"立起来"，过窄路姿态），遥控关闭后关节零力矩、四臂被重力砸下（"掉下去"）。

**根因**（代码定位）：模式管理器中启动/复位姿态硬编码为 `max_angle`(59°)；遥控失效时 `reset_count` 每 tick 递增 → 悬挂组件冻结 → 关节目标 NaN → 零力矩垮塌。

**方案（零代码侵入）**：新建试验配置 `deformable-infantry-omni-c-id.yaml`，**不加载底盘全部执行控制器**。关节与轮电机指令无人写入 → 硬件层对 NaN 自动发 disable（零电流）→ 四臂自然下垂、车轮自由，**"立起来又掉下去"物理上不可能发生**。

**验证**：四臂全程角度波动 < ±0.03 rad，整车静止 ✓

## 6. 系统辨识

### 6.1 模型

```
J·ω̇ + B·ω + τ_c·sign(ω) = τ_applied
```
- J：等效转动惯量；B：黏性阻尼；τ_c：库仑摩擦
- 注：输入用**实测作用力矩**（电调反馈电流换算），比控制器指令更接近真实输入

### 6.2 统一模型（本次核心产出）

用**输出误差法**（最小化自由仿真误差，三维网格搜索）在**两批数据合并**后拟合：

| 参数 | **统一模型** | 09-26 原标定 | 09-29 单独拟合 |
|---|---|---|---|
| J (kg·m²) | **0.137** | 0.150 | 0.150 |
| B (N·m·s/rad) | **0.530** | 0.661 | 0.125 ✗ |
| τ_c (N·m) | **0.360** | 0.201 | 0.584 ✗ |
| **训练集误差** | **0.333** ✓ | 0.883 | 0.486 |
| 验证集误差 | 0.162 | **0.140** | 0.120 |
| **★遥控数据误差** | **1.471** ✓ | 1.553 | 2.678 |

（归一化 RMS 误差，越低越好）

**统一模型是唯一能同时解释两批数据的参数组** ✓。物理自检：J/B = 0.258 s，转折频率 0.616 Hz，与实测阶跃响应一致 ✓

### 6.3 三个方法学发现（重要）

**① 一步预测 R² 是误导性指标** ✗
09-29 单独拟合的 R²=0.9997 比 09-26 的 0.9992 还高，但参数物理上是错的（τ_c=0.58 N·m 无法解释 0.3 N·m 下实测能动）。原因：极点 a=0.9994 时"预测 ω[k+1]≈ω[k]"的平凡解即可拿高分。**必须用自由仿真/阶跃响应做物理校验** ✓

**② 一步 ARX 存在系统性偏差（errors-in-variables）** ✗
输入含噪声时最小二乘有偏，导致 B 与 τ_c 互相抵消。改用**输出误差法**（直接最小化仿真轨迹误差）才能得到物理正确的参数 ✓

**③ B 与 τ_c 的分离依赖低频（准静态）数据**
第一轮的 0.05/0.1 Hz 工况提供了 τ_c 的关键信息；第二轮因 yaw 行程安全删除了它们 → 分离性显著下降。**这是安全约束与辨识可分离性之间的真实权衡** ✓

## 8.2 第三轮：放宽力矩后模型整定生效（决定性实验）

### 8.2.1 如何安全地放宽力矩上限

前两轮的共同症结是 2.5 N·m 限幅把三组控制器一起卡死 ✗。放宽的关键在于分清两件事：

| 现象 | 是否危险 | 处理 |
|---|---|---|
| pitch 被扰动/下垂 | **不危险** —— 它会落在机械限位上被结构托住，保持力矩降到 ~1 N·m，**不增加摩擦** | 测试前**预先把 pitch 压到最低位**，它就不可能中途再掉 ✓ |

因此：**yaw 力矩限幅 2.5 → 4.0 N·m**（电机 CAN 上限 4.5，留余量），行程保护保持 2.2 rad 不变。

附带收益：pitch 预先落位后保持力矩从 3.5 N·m 降到 ~1 N·m，**发热大幅下降** ✓（实测末温仅 40 °C）

## 9. 平台的两个硬约束（第二轮最重要的工程发现）

### 9.1 yaw 行程约束（线缆缠绕 / 机械干涉）

**现象**：某工况下 yaw 转出约 288° 后，pitch 被拽到机械下限（−10°）、yaw 同时卡死（激励 1.0 N·m 时转速为 0）✗

**定量**：

| yaw 转角 | pitch 表现 | 判定 |
|---|---|---|
| 0 ~ 143° | 世界角仅变 0.96°，力矩稳定保持 | ✓ 安全 |
| 143° ~ 288° | 快速旋转时已有 0.25° 下沉 | ⚠️ 耦合显现 |
| ~288° | 被拽到限位、yaw 卡死 | ❌ 危险 |

**机理**：准静态激励让 yaw 朝一个方向持续转出大角度 → 线缆拉紧/机械干涉 → 先拽下 pitch、再锁住 yaw

**应对**：① 行程保护 2.2 rad（126°）✓ ② 删除 0.05/0.1 Hz 危险工况 ✓ ③ 高扭矩高速度改由**提高频率**获得（ω_peak=(τ−τ_c)/B 与频率无关，偏转 ∝ 1/f）✓

### 9.2 pitch 力矩余量瓶颈

**现象**：yaw 激励 3.5 N·m 时 pitch 被撞落（世界角 +0.08° → −8.90°，yaw 速度峰值 4.51 rad/s 时掉得最快）✗

**量化**：
```
保持炮管需 3.5 N·m，电机上限 4.5 N·m  →  余量仅 ~1 N·m
yaw 3.5 N·m → α=(3.5−0.29)/J ≈ 22 rad/s² → 惯性扰动 > 1 N·m → pitch 被撞落
yaw ≤2.5 N·m → α ≤ 15 rad/s² → pitch 全程稳定 ✓
```

**双重后果**：
- **抗扰能力差**：yaw 一大就被撞掉
- **持续发热**：3.5 N·m 持续负载，实测 +4 °C/min，热平衡 **52 °C**

**改进方向**：pitch 轴**机械重力配平**（配重/拉簧）——一次性同时解决发热与抗扰 ✓ 这是后续最值得做的一项
