# 步兵 C 云台 Yaw 轴系统辨识与控制优化报告

> 项目：RoboMaster 步兵 C（deformable-infantry-omni-c）
> 平台：RMCS（ROS 2 控制系统），LK MG4010Ei10 yaw 电机，CAN2 @ 0x142
> 日期：2026-09-26

---

## 1. 目标与总体思路

本项目的目标是对步兵 C 云台 yaw 轴建立**二阶动力学模型**，用实车数据完成系统辨识，并基于辨识参数改进 yaw 控制，最后通过 A/B 对照实验验证改进效果。

技术路线：

```
梳理 yaw 控制数据流 → 下层解耦（隔离试验环境） → 设计标准激励协议
→ 采集标准数据集 → 二阶+摩擦模型拟合（交叉验证） → 模型前馈控制器
→ A/B 对照实验（基线 vs 模型） → 结论
```

## 2. 系统背景：yaw 控制数据流

原控制器为双环结构（`deformable_infantry_gimbal_controller`）：

```
遥控器/自瞄 → 角度误差(yaw_angle_error)
  → 角度 PID (kp=10)      → 速度参考
  → 速度 PID (kp=13, ki=0.02)，反馈为 IMU 角速度
  → 控制力矩 /gimbal/yaw/control_torque
  → LK 电机力矩-电流换算 → CAN2 0x142（约 500 Hz）→ MG4010Ei10
```

关键事实：

- yaw 速度环**没有输出限幅**，指令力矩最终仅受 CAN 电流 ±2048（约 ±4.5 N·m）物理钳位；
- 云台侧可用双速度源：电调编码器速度与 BMI088 IMU 陀螺（实测相关性 0.993，斜率 0.987，二者高度一致）；
- 主控制循环 1 kHz，yaw CAN 命令实际约 500 Hz。

## 3. 试验环境：下层解耦

### 3.1 问题描述

原始行为：上电后代码将四条轮腿摆臂收到 59° 高位（"立起来"，过窄路姿态），遥控器关闭后关节零力矩、四臂被重力砸下（"掉下去"）。根因（代码确认）：

- `deformable_mode.hpp` 中启动/复位姿态目标硬编码为 `max_angle`（59°）；
- 遥控失效时 `reset_count` 每 tick 递增 → 悬挂组件冻结 → 关节目标 NaN → 零力矩垮塌。

### 3.2 解耦方案（零代码侵入）

新建试验配置 `deformable-infantry-omni-c-id.yaml`：**不加载底盘全部执行控制器**（悬挂/轮控/4 个摆臂关节控制器）。无人写关节与轮电机指令 → LK/M3508 输入为 NaN → 硬件层自动发 disable（零电流）→ 四臂自然下垂、车轮自由，"立起来又掉下去"物理上不可能发生。

依赖修复：`referee::Command` 需要 `ChassisPowerController` 的超级电容充电限制信号，后者又需要 `DeformableChassis` 的控制模式信号——这两个组件保留（它们不驱动任何电机），姿态指令的消费者全部移除后它们的输出为悬空信号。

### 3.3 解耦验证

四臂全程角度波动 < ±0.03 rad（完全松弛）；车轮零电流；整车静止。解耦目标达成。

## 4. 标准激励协议

### 4.1 协议设计

编写了专用组件 `YawIdentificationController`（挂载于 rmcs_core 辨识组件库），触发后自动执行：

| 阶段 | 时长 | 内容 |
|---|---|---|
| phase 0 静置 | 15 s | 激励力矩 0，采集零偏 |
| phase 1 正弦 | 30 s | τ = A·sin(2πft) |
| phase 2 阶跃 | 5 s | ±0.8 N·m 正负交替 10 拍 |
| phase 3 跟踪 | 20 s | yaw 闭环跟踪脚本轨迹（A/B 对照实验用） |

设计要点：

- 仅协议期间写 CSV（带 `elapsed_s` 真实时间与 phase 标记），不产生杂散数据；
- yaw 控制权通过 `identification_active/identification_torque` 信号从云台控制器平滑移交，云台自身 yaw PID 每拍复位（防积分饱和），pitch 保持逻辑不受影响；
- 安全限幅：激励力矩硬限幅 1.5 N·m，IMU 角速度 > 6 rad/s 或遥控失效自动中止；
- 触发方式：遥控拨杆手势（双中 → 右拨杆上），现场零接线操作。

### 4.2 数据质量

- 采样精确 1 kHz，索引零缺口（50 s = 50,001 行）；
- 静置段陀螺零偏 +0.002 rad/s（std 0.011）；
- 双速度源一致性：corr = 0.993，斜率 0.987；
- 全程无激励削顶、无饱和。

## 5. 系统辨识

### 5.1 模型结构

yaw 轴绕竖直轴自由旋转（无回位弹簧），采用二阶 + 库仑摩擦模型：

$$J\,\dot{\omega} + B\,\omega + \tau_c\,\mathrm{sign}(\omega) = \tau(t)$$

离散化（1 kHz）后对参数线性，延迟 d 网格搜索 + 最小二乘求解。

### 5.2 辨识结果

训练集：正弦幅值 1.0 N·m 组；验证集：0.5 N·m 组（训练时完全未使用）。

| 参数 | 数值 | 物理含义 |
|---|---|---|
| **J_eq** | **0.150 kg·m²** | yaw 轴等效转动惯量 |
| **B_eq** | **0.66 N·m·s/rad** | 等效黏性阻尼 |
| **τ_coulomb** | **0.20 N·m** | 库仑摩擦力矩 |
| 机械时间常数 | ≈ 227 ms | dt/(1−a) |

### 5.3 三重验证

1. **训练集** R² = 0.9992（35 s 运动段，一步预测）；
2. **交叉验证** R² = 0.9953（验证集，独立数据）；
3. **物理校验**：±0.8 N·m 阶跃理论稳态速度 (0.8−0.2)/0.66 ≈ 0.91 rad/s，0.5 s 达 2.2 个时间常数 ≈ 0.75 rad/s——实测 0.72~0.77 rad/s，吻合。

### 5.4 摩擦非线性的实验证据

力矩从 0.5 → 1.0 N·m（2 倍），正弦峰值速度响应 0.23 → 0.79 rad/s（**3.4 倍**）：小力矩下系统大部分时间被静摩擦"咬住"，线性模型无法解释，带库仑摩擦项的模型是必要选择。这一现象本身就是答辩中"为什么模型要带摩擦项"的论据。

## 6. 控制器 A/B 对照实验

### 6.1 实验设计

跟踪段（20 s）：yaw 闭环跟踪脚本轨迹（±30° 阶跃 4 拍 + 0.5 Hz 正弦），轨迹过渡用 smootherstep 保证参考加速度有限。

| 组别 | 反馈控制 | 前馈 |
|---|---|---|
| baseline | 原级联 PID（10 / 13、0.02），复刻原积分语义 | 无（原手动模式行为） |
| model | **完全相同**的 PID | τ_ff = J·α_ref + B·ω_ref + τ_c·sign(ω_ref) |

唯一变量是前馈——指标差异可完全归因于辨识模型。

### 6.2 结果

| 指标 | baseline | model | 改善 |
|---|---|---|---|
| 调稳时间（2° 带，阶跃） | 385~401 ms | 280~392 ms | 首拍 **−30%** |
| 阶跃超调 | 1.87~2.46° | **0.43~1.31°** | **−60%~80%** |
| 正弦跟踪 RMS 误差 | 0.555° | **0.471°** | −15% |
| 跟踪总 RMS 误差 | 3.658° | **3.416°** | −6.6% |
| 峰值误差 | 30.53° | **28.89°** | −5.4% |

激励段一致性检查：两组开环响应峰值 0.844 / 0.831 rad/s——对比公平，差异可归因于前馈。

![A/B 跟踪对比](figures/fig4_ab_tracking.png)

![阶跃响应细节](figures/fig5_step_zoom.png)

### 6.3 解读

- **超调改善最显著（最多 −80%）**：模型前馈按 `J·α + B·ω + τ_c` 主动出力，PID 无需"先冲过头再拉回"，定位过程明显更稳；
- 改善幅度为中等的原因：原 PID 增益本身较激进，两组在大轨迹处均触及 4.0 N·m 跟踪限幅，前馈的发挥空间被部分压缩；
- 结论：**辨识参数正确，模型前馈有效**。

## 7. 结论与后续工作

### 7.1 结论

1. 完成了步兵 C yaw 轴的二阶 + 库仑摩擦建模与实车辨识，参数三重验证成立；
2. 建立了可复用的标准激励协议与试验配置（下层解耦，安全可重复）；
3. 模型前馈使阶跃超调降低 60~80%、调稳时间缩短 30%、跟踪误差全面下降——**参数修改正确**。

### 7.2 已知问题与改进方向

| 项 | 说明 | 建议 |
|---|---|---|
| yaw 速度环无输出限幅 | 指令可达 −34.8 N·m（物理钳位 ±4.5） | 配置加 `yaw_velocity_output_min/max` |
| 正弦参考起步速度不连续 | 阶跃→正弦切换处前馈理论尖峰（被限幅兜住） | 正弦参考用余弦爬坡起步 |
| CSV 无时间戳列 | 当前以 index×1ms 替代（采样无缺口，精确） | ValueCollector/协议组件加硬件时间戳 |
| 基线复刻路径差异 | 原控制器走"解算器+IMU 世界角"，试验走编码器角 | A/B 内部公平；报告已注明 |

### 7.3 后续工作

1. 将模型前馈以可选参数形式移植回正常比赛配置（`deformable-infantry-omni-c.yaml`），与自瞄前馈链路整合；
2. 基于辨识参数重新整定 yaw PID（按期望带宽计算而非试凑）；
3. 对 pitch 轴复用同一套"辨识协议 + 拟合 + 前馈"管线（需处理重力项）。
